Trang này không có trên site Pages

Nếu GitHub báo “The page you’re looking for has wandered off” thì chưa bật GitHub Pages hoặc URL sai / chưa deploy xong.

Vào repo trên github.com → Settings → Pages:

  • Chỉ upload bộ file đã build: Branch main, folder / (root)
  • Đẩy nguyên project này: Branch main, folder /docs

Đợi dòng Your site is live at … rồi mở đúng URL đó (có dấu / cuối).
